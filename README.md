# シフト作成アプリ（試験運用版 v.21）

介護老人保健施設の現場職員が、生成AIを設計の相談相手にしながら自作した**シフト自動作成アプリ**です。
第37回全国介護老人保健施設大会 栃木（2026年10月）の演題「現場発シフト自動作成アプリの開発と実践」で紹介しました。

## 特徴

- **ブラウザだけで動作**：インストール不要。`index.html` を開くだけで使えます
- **データは端末内だけに保存**：職員名やシフトは、お使いのPCのブラウザ内に保存されます。外部のサーバーには送信しません
- **機械が9割、人が1割**：各ステップの後に担当者が画面で確認・修正できる設計です
- **労務ルールの自動チェック**：連勤・夜勤過密・夜勤明け翌日の出勤、遅番の翌日の早番などの負担の大きい配置を避けます

## 動作環境

- パソコンの Google Chrome または Microsoft Edge（最新版を推奨）
- **起動時にインターネット接続が必要です**。画面の部品（React・Tailwind CSS・Babel）を外部の配信サイトから読み込むためです。職員データが送信されることはありません
- 想定規模：15名程度のワンフロア（二交代制）。これより多い人数にも対応できます

## ダウンロード方法

1. このページ右上の緑色の「**Code**」ボタンを押す
2. 「**Download ZIP**」を選ぶ
3. ダウンロードしたZIPファイルを展開（解凍）し、中の `index.html` をダブルクリックする

## 使い方（6ステップ）

画面上部のステップに沿って進めます。各ステップの後に結果を確認し、必要に応じて手で修正してください。

| ステップ | 内容 |
|---|---|
| 0 設定 | 職員・勤務条件・希望休を設定し、先月／当月のデータを読み込む |
| 1 確保 | 人手が足りなくなる日の日勤を先に確保する |
| 2 夜勤 | 夜勤を自動配置する |
| 3 日勤 | 明け・公休の展開、日勤の埋込、均しを一括で処理する |
| 4 早遅 | 早番・遅番を振り分ける |
| 5 早遅均 | 早番・遅番を均し、別パターンを作る |

初期状態では、見本として「職員A〜C」が登録されています。「職員設定」から自施設の職員に置き換えてください。

## データの保存について

- 入力した内容は、**使っているPC・ブラウザの中だけ**に保存されます。別のPCやブラウザには引き継がれません
- ブラウザの閲覧データを削除すると、保存内容も消えます。「設定保存」「CSV」でこまめにバックアップしてください
- **職員名を含むCSVや設定ファイルを、インターネット上（GitHubなど）に公開しないでください**
